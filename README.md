# 🌐 Manas Puthanpura — Portfolio Website

> A 3D interactive personal portfolio for a Data Scientist & AI Expert, built with React, TypeScript, and Three.js.

🔗 **[View Live Site](https://iammsp-star.github.io/portfolio-website/)**

---

## ✨ Features

- 🎨 Smooth scroll with GSAP ScrollSmoother
- 🤖 3D animated character model (Three.js + React Three Fiber)
- 💼 Projects showcase with animated cards
- 🛠️ Tech stack visual display
- 📅 Career & education timeline
- 📱 Fully responsive across mobile and desktop
- ✉️ Contact section

## 🛠️ Tech Stack

| Layer      | Technology                    |
|------------|-------------------------------|
| Framework  | React 18 + TypeScript         |
| Build Tool | Vite                          |
| 3D / Anim  | Three.js, GSAP, React Three Fiber |
| Deployment | GitHub Pages                  |

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
